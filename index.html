Tag complaints and negative reviews with a CFPB style theme taxonomy so ops can route root causes, not just apologise.

How it works

  • Seeded themes mirror public CFPB issue categories for debt settlement: services not provided, fees and charges, communication, payments, enrollment promises, and cancellation.
  • This is a transparent keyword baseline, not a black box model. Edit the JSON rules and re-run to match your own wording.
  • The promise versus outcome sub-tag flags texts that contain both a promise phrase and an outcome complaint phrase.
  • Sample complaints are paraphrased and synthetic, written for this demo. Never paste real consumer data into any public demo.
